## Overview

Australian Conveyancer is a digital news and media publication for the conveyancing profession, billed as "the practitioner's companion" with news, special reports, podcasts, and a magazine. The site runs on WordPress, and its dynamic features, including [The List](https://www.australianconveyancer.com.au/the-list/) and the listing creation flow, are powered by Aurelia 2, which slots directly into the existing WordPress site without convoluted tooling or workarounds.

## Features

- **The List**: A searchable industry directory covering jobs, professional conveyancing services, businesses for sale, and events, with reactive search and category and state filtering driven by Aurelia 2
- **Multi-Step Listing Creation**: A rich, multi-flow wizard that guides users through submitting a listing step by step
- **WordPress Integration**: Aurelia 2 drops into the existing WordPress site, enhancing only the parts that need rich interactivity

## Why Aurelia?

Aurelia 2 made it possible to build a rich, dynamic listing experience and embed it cleanly inside an existing WordPress site. Rather than rebuilding the whole site or fighting the framework with custom tooling and workarounds, Aurelia 2 slotted right into the pages that needed it, powering The List directory and the multi-step listing creation flow while leaving the rest of the WordPress site untouched.
